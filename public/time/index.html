Разбор выражения для иземерения времени в JavaScript

Исходный код

console.time('a');
((y = 2 ** 15, x = Date.now()) => { 
    while (Date.now() - x < y) ;
})();
console.timeEnd('a');

Разбор выражения

console.time('a')- запускает таймер с именем a

стрелочная функция: (y = 2 ** 15, x = Date.now()) => стрелочная функци с параметрами x, y: y получает значение 32768, x получает значение вызова функции - число миллисекунд на момент запуска функции

while (Date.now() - x < y) - цикл с разницей между текущим временем и временем начала x; пока прошло меньше 32768 миллисекунд, цикл ничего не делает и просто занимает процессор busy wait

console.timeEnd('a') - останавливает таймер и выводит в консоль измеренное время

IIFE

Immediately Invoked Function Expression (IIFE) — это немедленно вызываемое функциональное выражение в JavaScript. Это функция, которая выполняется сразу же после её определения.

Здесь, IIFE используется, чтобы создать локальную область видимости для переменных x и y и выполнить код один раз сразу после объявления функции.

без IIFE

console.time('a');
const y = 2 ** 15;
const x = Date.now();
while (Date.now() - x < y) ;
console.timeEnd('a');

Этот вариант работает аналогично исходному. Переменная y задаёт длительность задержки, переменная x хранит время начала выполнения, а цикл удерживает выполнение программы примерно 32.8 секунды.
